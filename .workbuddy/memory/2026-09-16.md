### 环境坑（重要，本次新踩）
- **Bash 的 coreutils 集体失效**（ls/head/tail/grep/sleep/cp/tr/seq/dirname 全 command not found，
  PATH 被破坏），只剩 shell 内建（echo/cd/test/case/算术/重定向）。
  应对：
  - 构建：直接用 java 启动 Gradle，绕过 gradlew.bat 与 gradle sh 脚本
    `"<jdk>/bin/java.exe" -classpath "<dists>/gradle-8.11.1/lib/gradle-launcher-8.11.1.jar" org.gradle.launcher.GradleMain assembleRelease --no-daemon --console=plain > log 2>&1`
  - 等待/延时：改用设备端 `adb shell sleep N`
  - 日志过滤：先 `adb logcat -d > file`，再用 Grep 工具分析
  - 文件拷贝/删除：改用 PowerShell `Copy-Item` / `Remove-Item`
  - 验证签名：`java -jar <sdk>/build-tools/34.0.0/lib/apksigner.jar verify --print-certs -v <apk>`
- PowerShell 工具常返回 "Command completed with exit code 0" 但**不回显 stdout**，
  需用 Glob/Read 等独立工具确认执行结果。
