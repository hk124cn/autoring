## auto-ring 项目：安卓情景音量与闹钟调度 App
- 用户需求：按时间段自动切换「闹钟音量 / 来电·通知模式（响铃·静音·震动）/ 震动开关」。
  场景：戴耳塞睡觉 -> 闹钟最大防睡过头；上班 -> 静音+震动不打扰别人。痛点：手动易忘/错。
- 关键可行性：Android 的 STREAM_ALARM 与 STREAM_RING 是两条独立音流，可分别设置。

## 已确认决策
- 实现方式：原生安卓 App（Kotlin + Gradle，Android Studio 打开 Run 到手机）。
- 装 App 能力：用户不确定，已评估——最省路是 Android Studio 一键 Run(debug)；本环境无 SDK/设备，无法代编 APK。
- 手机品牌：Realme / 真我（ColorOS）。需自启动白名单 + 电池不限制 + 勿扰权限引导。
- 模式数量：灵活增删。
- 新增目标（本回合）：做成可安装、可上架推广的产品——按 release 签名包(AAB/APK) 标准从第一天搭建；上架合规偏向 SCHEDULE_EXACT_ALARM；关注国内软著与隐私政策。
